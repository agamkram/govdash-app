Heat signals (activity overlays) + spending caches
Sources:
  USAspending toptier agencies — obligated/outlay amounts
    https://api.usaspending.gov/api/v2/references/toptier_agencies/
  USAspending sub-agency (subtier) under each toptier
    https://api.usaspending.gov/api/v2/agency/{toptier_code}/sub_agency/
  Federal Register — document counts since period start
    https://www.federalregister.gov/api/v1/
Refresh: npm run fetch:heat [-- --force] [-- --fr-limit 60]
         npm run fetch:subtier [-- --force]
Enrich:  npm run enrich:heat
         npm run enrich:spending
